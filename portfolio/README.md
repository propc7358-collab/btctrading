# 投資水位紀錄

一個單檔、免安裝的內部網頁（`index.html`），用來記錄各平台的基金持有與投資水位。

## 使用方式

- 直接用瀏覽器打開 `portfolio/index.html`（或用 GitHub Pages 開這個資料夾）。
- 資料存在瀏覽器的 localStorage，不會上傳到任何地方。換裝置前請按「匯出」備份 JSON，在新裝置按「匯入」。
- 第一次打開時，會載入 2026/11/10 兩個平台截圖上的持有資料。

## 功能

- **總覽**：總參考現值、投入本金、未實現損益、和上次快照比的變化。
- **投資水位**：在「投資水位 → 設定」輸入可投資總資金，水位 = 已投入本金 ÷ 可投資總資金。
- **持有明細**：依平台分組，可以新增、編輯、刪除持有，也能幫平台改名。只知道現值和報酬率時，填報酬率會自動反推本金。
- **依基金合併**：跨平台的同名基金（例如安聯台灣科技基金）會合計在一起。長條是現值，刻度線是本金。
- **配置比例**：依平台和類別算占比。
- **水位走勢**：每次更新現值後按「記錄今日快照」，累積下來就會畫成現值和本金的走勢。同一天重複記錄會覆蓋當天那一筆。

損益顏色用台灣慣例：紅色是賺，綠色是賠。
