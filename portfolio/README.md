# 投資水位紀錄

用瀏覽器打開 `index.html` 就能看，資料來自同一個資料夾裡的 `data.js`。

## 更新方式

把基金 App 的截圖傳給 Claude，並說明是哪個帳戶。Claude 會在 `data.js` 新增一筆紀錄，然後 push，流程寫在 repo 根目錄的 `CLAUDE.md`。

- **持股沒變動**：這次的變化就是單純的淨值漲跌，會累積成淨值走勢。
- **持股有變動**（新增、加碼、減碼、出清）：會自動辨識並列在「截圖紀錄」。淨值變動會扣掉新投入的本金，不會把加碼算成獲利。

## 頁面內容

- **總覽**：總現值、本金、未實現損益，還有和上次紀錄比的淨值變動。設了可投資總資金時，也會顯示投資水位。
- **持有明細**：各帳戶最新一筆截圖。每檔基金都有「較上次」的淨值變動 %。
- **依基金合併**：跨帳戶的同名基金合計，加上帳戶別、類別的配置比例。
- **水位走勢**：可以切換看全部帳戶合計，或看單一基金。
- **截圖紀錄**：每次上傳的明細和持股變動。
